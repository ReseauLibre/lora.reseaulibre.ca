A quick word to announce the new [nodes section](../../references/nodes/index.md) which features
repeaters. There is one page per operator, and currently only one
operator, but more are welcome!

And speaking of which, a new set of mirrors has been opened. The
source code for the site is visible at:

- Codeberg: <https://codeberg.org/reseaulibre/lora-reseaulibre-ca/>
- sourcehut: <https://git.sr.ht/~anarcat/lora.reseaulibre.ca>
- GitLab: <https://gitlab.com/reseaulibre/lora.reseaulibre.ca>
- GitHub: <https://github.com/ReseauLibre/lora.reseaulibre.ca>

We prefer contributions to come in to Codeberg, but following our
spirit of universality and reducing friction for contributions we also
accept contributions from the other sites. A more [detailed
justification of the GitHub is visible here](https://codeberg.org/reseaulibre/lora-reseaulibre-ca/commit/1ce3d5b1c13cf8e90efd417e1505294c8a621a3a).

Finally, this was done by some work on the site's template, which was
made possible by a switch from the old [`mkdocs-material`](https://squidfunk.github.io/mkdocs-material/) to
[Zensical](https://zensical.org/) engine. This changed the theme header and some fonts,
but the site is mostly similar. The only change is that the git-based
change date has been removed while Zensical [implements the missing
functionality](https://github.com/zensical/backlog/issues/18).
