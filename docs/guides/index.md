# Guides

Réseau Libre is [inclusive](https://en.wikipedia.org/wiki/Inclusivism) or "[ecumenical](https://en.wiktionary.org/wiki/ecumenical)" in the sense that
it profess "faith" in a single technology. We therefore have guides
for multiple mesh protocols and tools.

> [!TIP]
> If you're looking for [hardware listings](../references/hardware/index.md), you'll find that in the
> [references](../references/index.md) along with other documentation.

- [MeshCore](meshcore/index.md): most popular alternative, solid mesh in Montreal, if
  you're new, **start here**
- [Reticulum](reticulum/index.md): currently being tested and researched, if you're
  looking for a **more secure and flexible solution** that works over
  WiFi, ham radio, LoRa and carrier pigeon, start here
- [Meshtastic](meshtastic.md): **deprecated** since [April 2026](../news/posts/2026-05-02-meshtastic-deprecated.md), we keep the
  documentation for historical reference but do not recommend its use
  anymore

- the [weekly net procedures](net.md)
